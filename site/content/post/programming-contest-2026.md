## 활동 개요
- 활동: 2026 프로그래밍 경진대회 (전북대학교 SW중심대학사업단)
- 시기: 2026년 5월 (상장 수여일 2026-05-09)
- 상태: 완료
- 결과: 도전상 수상

## 목적
제한 시간 안에 알고리즘 문제를 정확하게 풀어내는 능력을 점검하고, 실력 향상을 위해 참가하게 되었습니다.

## 나의 역할
개인전이라 문제 읽기, 풀이 설계, 코드 작성, 제출까지 전 과정을 직접 수행했습니다.

## 수행 과정과 언어 선택 이유
- 형식: 개인전, 제한 시간 3시간
- 사용 언어: C++
- C++을 선택한 이유: 시간제한이 널널하지 않을 수도 있다고 생각하여 비교적 빠른언어인 C++을 사용하였습니다.
- 준비 방법: alps 동아리에서 알고리즘 문제를 풀며 준비하였습니다.

## 산출물과 결과
- 도전상 수상
- 3시간 동안 알고리즘 문제를 C++로 직접 풀어 제출했고, 제한 시간 안에 풀 수 있는 문제를 우선 해결했습니다.
## 배운 점과 개선 방향
- 배운 점: 아직 많이 부족하고 문제 푸는 시간이 너무 오래걸린다고 생각하였습니다.
- 아쉬운 점: 실력이 부족해서 많은 문제를 못푼거 같아 아쉽습니다.
- 다음 계획: 다음번에 도전하기 전에는 매주 알고리즘 문제를 주에 3문제씩 풀고 시간을 재면서 풀어 문제 풀이 속도를 줄여보겠습니다.
